# 📐 로롱수학 (Lorong Math) - 신나는 맞춤형 수학 모험!

로롱수학은 만 4세부터 초등학교 3학년을 대상으로 하는 놀이형 맞춤 수학 학습 웹 애플리케이션입니다.  
본 프로젝트는 **GitHub Pages** 정적 호스팅 서비스에 즉각 호스팅되도록 빌드 단계 없이 브라우저에서 다이렉트로 실행되는 SPA(Single Page Application) 구조로 제작되었습니다.

---

## ✨ 핵심 기능 및 특징

1. **유아 맞춤형 적응형 레벨테스트 (Screen 02)**
   - 쉬운 수 세기부터 곱셈구구까지 8문제를 푸는 도중 정답 여부에 따라 실시간으로 난이도를 변경하는 **적응형 진단 평가(Adaptive Diagnostics)**를 제공합니다.
   - 테스트 결과에 따라 Stage 1 ~ Stage 5 중 최적의 코스가 자동으로 배정됩니다.

2. **무한 문제 생성 엔진 (Screen 03, 04)**
   - "새로운 문제 생성하기" 버튼을 통해 난수를 사용한 절차적 생성(Procedural Generation) 기법으로 **무제한 수학 학습 세트**를 즉석 발급받아 학습할 수 있습니다.
   - 각 세트는 **'4+1 문항 학습법'**에 따라 구성됩니다.
     - **Q1 ~ Q3 (개념 탄탄):** 직관적이고 쉬운 수학/연산 문제
     - **Q4 (응용 한 스푼):** 개념을 실생활과 대입한 이야기식 문제
     - **Q5 (로롱 씽크):** 사고력과 퍼즐, 거꾸로 유추하는 난이도 높은 문항

3. **난이도 및 문항별 차등 보상 시스템**
   - 높은 스테이지일수록, 그리고 어려운 문항일수록 획득하는 도토리(🌰)의 개수가 차등화됩니다.
     - **Stage 1:** 정답당 도토리 1개 획득
     - **Stage 2:** 정답당 도토리 2개 획득
     - **Stage 3:** 정답당 도토리 3개 획득
     - **Stage 4:** 정답당 도토리 4개 획득
     - **Stage 5:** 정답당 도토리 5개 획득
   - 가장 난이도가 높은 **Q5 (씽크 문항)** 정답 시에는 해당 난이도 기본 보상의 **2배**를 획득합니다 (예: Stage 5는 +10개).
   - 5문제 세트 학습을 모두 완료하면 `스테이지 레벨 × 5`개의 완료 보너스가 추가 지급됩니다.

4. **로롱이의 요술 방 꾸미기 (Screen 06)**
   - 모은 도토리 🌰를 가지고 상점 탭에서 코스튬(모자, 안경, 의상) 및 인테리어 가구(벽지, 식물, 장난감)를 구입할 수 있습니다.
   - 구매한 아이템은 로롱이 마이룸 화면에 즉각적으로 장착/장식 반영됩니다 (의상 레이어 오버레이 시스템).

5. **오답 복습 노트**
   - 틀린 문제는 자동으로 오답 노트에 저장됩니다. 로드맵 상단에서 언제든 오답 노트를 열어 개별 다시 풀기 또는 모아 풀기로 복습(도토리 추가 보상)할 수 있습니다.

6. **Web Audio & Speech TTS 시스템**
   - Web Speech API를 활용하여 모든 문제를 어린이를 위해 상냥한 한국어로 직접 읽어주는 **TTS 기능(🔊)**이 탑재되어 있습니다.
   - 외부 음악 에셋 다운로드 없이 브라우저 단독으로 아기자기하고 귀여운 레트로 사운드(정답, 오답, 클릭, 도토리, 팡파레)를 합성하는 **Web Audio Synth**가 적용되었습니다.

## 🚀 GitHub Pages 배포 가이드

본 저장소(`https://github.com/mhsssshin/RR_Math.git`)를 사용하여 GitHub Pages를 활성화하려면 아래 단계를 따르세요.

1. 이 리포지토리에 소스 코드를 푸시합니다:
   ```bash
   git add .
   git commit -m "feat: 로롱수학 정적 SPA 앱 완성 및 무한 문제생성/차등보상 적용"
   git push origin main
   ```
2. GitHub 리포지토리의 웹 페이지 설정으로 이동합니다:
   - GitHub 저장소 상단 메뉴의 **Settings** -> 왼쪽 메뉴의 **Pages** 클릭.
   - Build and deployment의 **Branch** 영역에서 `main` 브랜치 및 `/ (root)` 디렉토리를 선택하고 **Save**를 클릭합니다.
3. 약 1~2분 후 배포가 완료되면 `https://mhsssshin.github.io/RR_Math/` 주소로 접속해 서비스를 즉시 사용하실 수 있습니다!
